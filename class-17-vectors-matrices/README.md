# Class 17 - Vectors and Matrices

Examples of arrays (vectors) and 2D arrays (matrices) in C.

## Files

- **[vectors.c](./vectors.c)**: Demonstrates 1D arrays with different storage classes (local automatic, local static, and global), showing how each is initialized and printed.
- **[matrices.c](./matrices.c)**: Demonstrates operations on 3x3 matrices (`double[3][3]`), including matrix addition, matrix multiplication, and printing a matrix.

## Build

```sh
gcc vectors.c -o output/main.exe
gcc matrices.c -o output/matrices.exe
```
