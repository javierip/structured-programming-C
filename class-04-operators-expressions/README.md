# Class 04 - Operators and Expressions

Demonstrates arithmetic operators, integer division, type casting, and math library functions in C.

## Concepts Covered

- **Arithmetic operators:** `+`, `-`, `*`, `/`, `%`
- **Integer division:** truncation behavior when dividing two integers
- **Modulo operator:** obtaining the remainder of a division
- **Type casting:** converting between `int` and `double` for precise results
- **Math library:** using `sqrt()` from `<math.h>`

## Build and Run

```bash
sh build.sh
```

The script compiles the program and runs it automatically. The binary is placed in the `output/` directory.

> **Note:** The `-lm` flag is required to link the math library (`<math.h>`).

## Files

- `main.c` — Program source code
- `build.sh` — Compilation script
- `output/` — Compiled binary output
