# Class 06 - Flow Control

Examples of flow control structures in C: `if` statements and `switch`/`case`.

## Programs

### main-if.c — Rock Paper Scissors

A simple Rock Paper Scissors game that demonstrates the use of `if` statements.

- The user selects rock (1), paper (2), or scissors (3)
- The machine's play is hardcoded to paper
- All possible matchups are evaluated with `if` conditions and the result is printed

**Concepts:** `if`, logical operators (`&&`), named constants (`const int`)

---

### main-switch.c — Month Number to Name

Converts a month number (1–12) into its corresponding name using a `switch` statement.

- The user enters a number
- The `switch` block matches it to the month name and prints it
- Invalid input (outside 1–12) triggers the `default` case and prints `ERROR`

**Concepts:** `switch`, `case`, `default`, `break`
